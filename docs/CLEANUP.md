# מה אפשר למחוק / לא להעלות ל-Git

- **Procfile** — הקובץ ריק, וההפעלה כבר מוגדרת ב-`railway.json`. אפשר למחוק.
- **`.venv/`** — הסביבה הווירטואלית המקומית. לא עולה ל-Git (כבר ב-`.gitignore`), אפשר ליצור מחדש עם `pip install -r requirements.txt`.
- **`__pycache__/`** — נוצר אוטומטית, לא עולה ל-Git, אפשר למחוק בלי חשש.
- **גרסאות כפולות של אותו קובץ** (למשל כמה README, כמה main.py) — להשאיר רק את הגרסה האחרונה.
